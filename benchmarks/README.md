# Benchmark Skeleton

This folder provides a lightweight benchmark harness for CortexNode.

## Files

- `scenarios.json`: Prompt set with simple expected substring checks.
- `results/`: JSON outputs generated by the benchmark script.
- `results/trend.md`: Auto-generated trend summary across recent benchmark runs.

## Run (dry-run skeleton)

```bash
python scripts/benchmark.py --cases benchmarks/scenarios.json --output benchmarks/results/local-skeleton.json
```

Dry-run mode validates benchmark definitions and emits a structured report without invoking the model.

## Run live benchmark

```bash
python scripts/benchmark.py \
  --live \
  --cases benchmarks/scenarios.json \
  --output benchmarks/results/local-live.json
```

Live mode executes `main.py --prompt` for each scenario and measures latency.

## Trend Report

```bash
python scripts/benchmark_trend.py --results-dir benchmarks/results --output benchmarks/results/trend.md
```

The trend report includes recent pass rate and latency deltas vs the previous run.
